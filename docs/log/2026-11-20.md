## Decided (by Jan)

- A pnpm workspace with three packages, so boundaries are enforced by the package manager.
  [ADR 0001](../adr/0001-workspace.md)
- Hosting moves to Cloudflare now, not at the first server-side need.
  [ADR 0002](../adr/0002-hosting.md)
- strm-ui tokens are written as CSS custom properties; no token build step.
  [ADR 0003](../adr/0003-token-source-format.md)
